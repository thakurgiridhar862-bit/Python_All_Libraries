# 🏏 IPL Data Analyzer

A comprehensive IPL data analysis project built using Python, Pandas, NumPy, Matplotlib, and Seaborn. This project analyzes IPL match and ball-by-ball datasets to uncover valuable insights about teams, players, venues, seasons, batting, bowling, and overall tournament statistics.

---

## 📌 Project Overview

This project analyzes IPL data from **2008 to 2016** using Python and data analysis libraries.

The project covers:

* Match Analysis
* Team Performance Analysis
* Player of the Match Analysis
* Batting Analysis
* Bowling Analysis
* Dismissal Analysis
* Venue Analysis
* Season Analysis
* Correlation Analysis
* Data Visualization

---

## 📂 Datasets Used

### 1. data.csv

Contains match-level information:

* Match ID
* Season
* Teams
* Venue
* City
* Winner
* Player of the Match

### 2. deliveries.csv

Contains ball-by-ball information:

* Match ID
* Batsman
* Bowler
* Runs Scored
* Dismissals
* Extras
* Wickets

### Dataset Period

**IPL 2008 – IPL 2016**
